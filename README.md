# NppSaveAsAdmin Revived

An unofficial continuation of the original [NppSaveAsAdmin](https://github.com/Hsilgos/nppsaveasadmin) plugin by Hsilgos.

This fork aims to restore and maintain compatibility with modern versions of Notepad++, while preserving the original plugin's functionality.

**Original project:** [Hsilgos/nppsaveasadmin](https://github.com/Hsilgos/nppsaveasadmin)

**Status:** Community-maintained fork. Not affiliated with the original author.
